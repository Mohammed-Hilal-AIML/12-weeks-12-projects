# Dataset

Use Kaggle **Chest X-Ray Images (Pneumonia)**.

Place it here:

```text
data/chest_xray/
├── train/NORMAL/
├── train/PNEUMONIA/
├── val/NORMAL/
├── val/PNEUMONIA/
├── test/NORMAL/
└── test/PNEUMONIA/
```

`validation/` is also accepted instead of `val/`.

Do not upload the dataset to GitHub.
